# APIConfig

    Les agendas côté UCA, nommés "agendas" : ils contiennent au moins un ID puisque c'est ce dernier qui nous permet de récupérer le fichier associé sur l'UCA.
    Les "alerts" : elles doivent au moins contenir le destinataire et l'agenda associé. Il est aussi possible de préciser quand envoyer l'alerte (toujours, seulement si une salle change, etc.).
